# Trusted Sources — the grounding policy of Agentic CoLearn

Every fact a student sees in this app must be traceable to an **official or
government source**. Content is generated by LLMs, but generation is
*grounded*: lessons and questions cite ingested excerpts of official
textbooks, an independent adversarial verifier tries to refute everything
before it is stored, and anything unverifiable is labelled — never disguised
(see `lib/verifier.ts`, `docs/ENHANCEMENTS.md` Batches 1-2).

This document is the registry of the sources that policy allows, per feature.

## 1. School curriculum (CBSE, Grades 1-12)

| Source | URL | Used for |
|---|---|---|
| NCERT textbooks | https://ncert.nic.in/textbook.php | The grounding corpus. `scripts/ingest-ncert.ts` downloads official chapter PDFs (code registry: `lib/ncert-codes.ts`), parses and chunks them into `ContentChunk`. Lessons/questions must cite these excerpts. |
| NCERT Learning Outcomes documents | https://ncert.nic.in | The coded LOs (`6.Sc.LO1`, …) seeded per chapter. |
| CBSE Academic | https://cbseacademic.nic.in | Curriculum documents, board typology (question patterns, competency-based policy). |
| CBSE | https://www.cbse.gov.in | Board announcements and schemes of study. |
| DIKSHA | https://diksha.gov.in | Government school-learning platform (energized textbooks, practice) — approved-search domain. |
| ePathshala | https://epathshala.nic.in | NCERT's official e-book portal — approved-search domain. |

The Tavily-backed web search is **hard-restricted** to these domains
(`lib/approved-search.ts`); the allow-list is re-enforced on every result.

## 2. Content languages — Hindi and Telugu

Hindi and Telugu content is **never machine-invented**. The pathway is
NCERT's own parallel-language editions, ingested through the same pipeline
(`npm run ingest:ncert -- --grade N --lang hi|te`):

| Language | Source | Code pattern | Coverage |
|---|---|---|---|
| Hindi | NCERT Hindi editions, ncert.nic.in | grade letter + `h` (e.g. `jesc1` → `jhsc1`, Class 10 विज्ञान) | Classes 1-12 (same books as English) |
| Telugu | NCERT Telugu editions (NCF series), ncert.nic.in | grade letter + `tl` (e.g. `fegp1` → `ftlgp1`, గణిత ప్రకాశ్) | **Classes 1-8 only** — NCERT publishes no Telugu editions for 9-12 |

Both patterns were verified empirically against ncert.nic.in (Aug 2026) —
see the comment in `lib/ncert-codes.ts`. Every download is validated (PDF
magic bytes + minimum length), so a missing edition fails loudly instead of
ingesting garbage.

**Honest fallback**: when a chapter's Hindi/Telugu edition is not ingested,
`lib/corpus.ts` grounds in the English excerpts and the lesson is written as
a *faithful translation of those excerpts only* — the UI labels this
"translated from the English NCERT edition". No facts may be added in
translation (`app/api/lesson/route.ts`).

**Telugu, Classes 9-12**: the official sources are the state SCERT e-books —
SCERT Telangana (https://scert.telangana.gov.in, e-books section) and SCERT
Andhra Pradesh (https://apscert.gov.in). These follow the state syllabus,
not CBSE/NCERT chapter structure, so they are **documented here as the
trusted source but not yet wired into the ingest registry**; until then,
Telugu for 9-12 uses the labelled-translation fallback above.

## 3. Olympiad preparation (Indian Talent Olympiad)

Registry: `lib/olympiad-data.ts`. Every exam fact (list, classes, 35/50-MCQ
pattern, 65-minute duration, section structure, syllabus alignment) was
researched from the official site in Aug 2026:

| Source | URL | Provides |
|---|---|---|
| ITO exam list | https://www.indiantalent.org/olympiad-exams | The exams (ISO, IMO, EIO, GKIO, ICO, NLRO, NSSO, NHO, CIO, NESO, IDO, …) and classes covered |
| ITO exam pattern | https://www.indiantalent.org/olympiad-exam-pattern | 35 MCQs (classes 1-4) / 50 MCQs (classes 5-10); subject + logical reasoning + HOT sections |
| ITO syllabus | https://www.indiantalent.org/olympiad-syllabus | "The questions asked in these exams are based on school curriculum. It suits all boards namely CBSE, ICSE and other State boards." |
| ITO sample papers | https://www.indiantalent.org/olympiad-sample-papers | Official free sample papers per subject/class |
| ITO exam schedule | https://www.indiantalent.org/olympiad-exam-schedule | Annual exam dates (typically December / February) |
| ITO FAQ | https://www.indiantalent.org/faq | Duration (65 min), Level 2 qualification, fees |
| NCERT Exemplar | https://ncert.nic.in/exemplar-problems.php | Official HOTS-style problem books (Maths & Science, 6-12) — the model for the Achievers section |
| HBCSE Olympiads | https://olympiads.hbcse.tifr.res.in | The national IOQM/NSE olympiad track — advanced enrichment beyond ITO |

Because ITO's syllabus **is** the school syllabus, Olympiad *study material*
reuses the app's grounded NCERT chapter workspaces; only the MCQ practice
style is Olympiad-specific. Subject and HOTS practice questions are anchored
to (and, where ingested, grounded in) the class's real NCERT chapters; the
logical-reasoning section is syllabus-independent by ITO's own design and is
generated as self-contained, deterministically-solvable puzzles, then passed
through the same adversarial verifier as everything else.

Known naming caveat: ITO's "IMO"/"EIO" abbreviations collide with the SOF
exams of the same names (sofworld.org). Everything in this app refers to the
**Indian Talent Olympiad** exams.

## 4. What is deliberately NOT a source

- Coaching-site content, blogs, question dumps and third-party "olympiad
  banks" — unverifiable provenance.
- Model memory beyond the named chapter: when a chapter's corpus is missing,
  prompts restrict generation to the named NCERT chapter and instruct the
  model to omit anything it is unsure of; the result is labelled
  **Generated**, not **Grounded**.
- Machine translation presented as native content — translations are always
  labelled (see §2).
